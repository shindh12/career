# L0. 상세 소개

> **"요구사항의 품질을 비교·판단해 아키텍처 결정을 내립니다"**

## 🌟 Core Competencies

### 1. Architecture & Decision Making

성능, 정합성, 확장성, 운영 복잡도처럼 충돌하는 요구사항을 비교하며 설계합니다.  
“왜 이 선택이 맞는지”를 설명할 수 있는 구조를 중요하게 봅니다.

### 2. Operational-first Design

정상 흐름보다 실패 가능성을 먼저 고려합니다.  
언제 깨질 수 있는지, 어떤 지표로 감지하고 어떻게 대응할지까지 설계에 포함합니다.

### 3. Data-first Perspective

데이터 모델, 쿼리 실행계획, 락 범위, 확장성을 기준으로 설계를 시작합니다.  
코드 이전에 DB에서 결정되는 한계를 먼저 봅니다.

### 4. Team-oriented Engineering

개인 최적화보다 팀이 같은 판단을 하게 만드는 것을 중요하게 생각합니다.  
아키텍처 리뷰, 트렌드 세션, 스터디 리딩을 통해 개발 문화를 만들어왔습니다.
