복잡한 리워드 정책과 예산 예측 시뮬레이션

1. 문제 (Problem)​

예측 불가능한 비용 리스크​

"AI 키워드 퀴즈" 에서 혜택은 다양한 지급 정책(선착순, 랜덤, 전원 지급)을 가집니다. 특히 랜덤 지급의 경우, 실제 유저가 얼마나 몰릴지, 얼마나 정답을 맞출지에 따라 예산 소진 속도가 예측 불가능했습니다.

  • Risk: 예산이 예상보다 많이 소진되거나, 반대로 예산이 너무 많이 남아 마케팅 효율이 떨어지는 현상.
  • Difficulty: 운영자가 정책을 변경할 때(예: 1등 당첨 확률 0.1% -> 0.5%), 이것이 비용에 미칠 영향을 직관적으로 알기 어려움.

2. 전략 (Strategy)​

A. 퍼센테이지 기반 동적 정책 설계​

리워드 지급 로직을 하드코딩하지 않고, 유연한 확률 기반으로 설계했습니다.

  • Probabilistic Model: 각 등수/금액별 당첨 확률을 0.0000~1.0000 정밀도로 설정 가능하도록 DB 설계.

B. 어드민 시뮬레이션(Simulation) 기능​

운영자가 정책을 배포하기 전에 미리 결과를 예측해볼 수 있는 도구를 개발했습니다.

  1. 입력: 예상 참여자 수(N명), 설정한 리워드 정책.
  2. 프로세스: 몬테카를로 시뮬레이션(Monte Carlo Simulation) 기법을 활용하여 N번의 가상 참여를 수천 회 반복 수행.
  3. 출력: Min / Max / Average / p95 / p99 예상 비용.

3. 결과 (Result)​

  • 운영 효율성: 예산 초과 사고를 예방하고, 운영자가 예상치 내에서 공격적인 마케팅 정책을 시도 가능.
