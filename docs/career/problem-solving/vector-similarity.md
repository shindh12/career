# 유사도 계산의 일관성 확보와 UX 개선

## 1. 문제 (Problem)

### 단순 코사인 유사도의 한계

AI 키워드 퀴즈 서비스에서 정답과 오답 사이의 유사도를 판단할 때, 단순한 벡터 유사도(Cosine Similarity)만으로는 해결하기 어려운 문제들이 발생했습니다.

- **모호한 경계**: 정답에 꽤 가까운 단어임에도 유사도가 0.6~0.7 수준에서 포화(Saturation)되어, 사용자가 "거의 다 맞췄다"는 느낌을 받기 어려움.
- **부적절한 연광성**: 제휴사나 광고주가 특정 경쟁사 키워드나 부정적인 단어와 연관되는 것을 원치 않음.

## 2. 전략 (Strategy)

### A. Contextual Embedding & 사전 구축

단어 자체의 의미뿐만 아니라 문맥을 반영하기 위해 `Contextual Embedding` 모델을 활용했습니다.

1.  **추천어 사전 (Positive Context)**: 정답과 관련된 설명이나 뉘앙스를 Context로 함께 주입하여, 정답 벡터가 더 풍부한 의미를 가지도록 조정.
2.  **부정어 사전 (Negative Context)**: 정답과 멀어지길 의도한 단어들(경쟁사, 오답 유도 단어)은 별도 사전을 구축해 의미적으로 거리가 먼 벡터를 조회하도록 강제.

### B. Quantile 기반 점수 재매핑 (Score Remapping)

단순 코사인 유사도는 정답에 매우 가까워도 낮은 수치(예: 0.6)가 나올 수 있습니다. 이를 해결하기 위해 **유사도 분포를 기반으로 정답(100점)에 수렴하도록 점수를 매핑**했습니다.

- **분포 기반 매핑**: 정답 단어와의 유사도 분포를 미리 계산하여 백분위수(Quantile)를 기준으로 점수를 부여.
  - `p90` (상위 10%) → **80점** (아까운 점수)
  - `p95` (상위 5%) → **90점** (정답과 관련된 단어)
  - `p99` (상위 1%) → **95점 이상** (정답 근접)
- **효과**: 사용자는 자신의 입력이 정답에 가까워지고 있음을 직관적인 점수와 피드백으로 인지하여 몰입감 증대.

## 3. 결과 (Result)

- **UX 개선**: 단순 계산이 아닌 사용자가 **실제 정답에 가까워지고 있음**을 체감할 수 있도록 개선.
- **브랜드 안전성**: 제휴사가 원치 않는 연관 검색어 노출을 기술적으로 차단.
